# Sudoku Master - 高级数独游戏

一个功能丰富、界面美观的网页版数独游戏，具有现代化的UI设计和多种游戏模式。

## ✨ 主要特性

### 🎨 现代化UI设计
- 渐变背景和动画效果
- 响应式设计，支持移动端
- 美观的按钮和过渡动画
- 动态星空背景

### 🎯 多种难度级别
- **简单**: 35个空格，适合初学者
- **中等**: 45个空格，标准难度
- **困难**: 55个空格，需要推理
- **专家**: 65个空格，挑战极限

### 🎮 多样化游戏模式
- **经典模式**: 传统数独规则
- **计时模式**: 比赛时间，挑战速度
- **禅境模式**: 无时间限制，放松游戏

### 🛠️ 丰富的工具栏
- **笔记模式**: 在单元格中添加候选数字笔记
- **提示系统**: 获取智能提示
- **撤销/重做**: 支持操作历史
- **自动填充**: 显示可能的候选数字
- **清除工具**: 快速清除单元格

### 🧠 思考链系统
- 显示求解步骤和推理过程
- 解释不同的数独解题技术
- 学习数独解题方法

### 🎊 特效和音效
- 游戏完成时的庆祝动画
- 粒子效果
- 错误提示动画
- 可自定义音效

### 📊 游戏统计
- 详细的游戏数据统计
- 最佳时间记录
- 提示使用情况
- 不同难度和模式的统计

### 💾 本地存储
- 自动保存游戏设置
- 统计数据持久化
- 支持数据重置

## 🚀 如何使用

1. 打开 `index.html` 文件
2. 选择难度等级和游戏模式
3. 点击"新游戏"开始游戏
4. 使用鼠标或键盘输入数字
5. 利用工具栏的各种功能辅助游戏

## 🎮 游戏操作

### 键盘快捷键
- `1-9`: 输入数字
- `Delete/Backspace`: 清除单元格
- 方向键: 移动选中单元格

### 鼠标操作
- 点击单元格选中
- 双击进入笔记模式
- 使用工具栏按钮

## 🎯 数独规则

数独是一个9x9的网格游戏，需要在每个单元格中填入1-9的数字，满足以下条件：

1. **行规则**: 每行必须包含1-9的所有数字
2. **列规则**: 每列必须包含1-9的所有数字
3. **宫规则**: 每个3x3的小宫格必须包含1-9的所有数字
