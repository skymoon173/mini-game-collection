# 🔧 数独小程序调试指南

## 🚀 快速开始调试

### 1. 环境准备

#### 安装微信开发者工具
1. 下载并安装微信开发者工具
   - 访问：[微信开发者工具下载](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
   - 选择适合你系统的版本

2. 注册微信小程序账号
   - 访问：[微信公众平台](https://mp.weixin.qq.com/)
   - 注册小程序账号并获取 AppID

#### 导入项目
1. 打开微信开发者工具
2. 点击"导入项目"
3. 选择项目目录：`微信小程序版`
4. 填入你的 AppID
5. 点击"确定"

### 2. 基本调试流程

#### 启动调试
1. 在开发者工具中点击"编译"
2. 等待编译完成
3. 使用模拟器或真机调试

#### 检查控制台
1. 在开发者工具中打开"控制台"标签
2. 查看是否有错误信息
3. 关注 `console.log` 输出

### 3. 常见问题排查

#### 问题1：页面无法加载
**症状**：小程序显示空白或错误页面
**排查步骤**：
1. 检查 `app.json` 中的页面路径是否正确
2. 确认所有必要文件都存在
3. 查看控制台错误信息

#### 问题2：功能无法使用
**症状**：按钮点击无响应
**排查步骤**：
1. 检查 WXML 中的事件绑定是否正确
2. 确认 JS 方法名拼写正确
3. 查看控制台是否有 JavaScript 错误

#### 问题3：样式显示异常
**症状**：界面布局错乱
**排查步骤**：
1. 检查 WXSS 文件语法
2. 确认 rpx 单位使用是否正确
3. 在不同设备模拟器中测试

## 🔍 调试功能

### 启用调试模式

在 `pages/index/index.js` 中，将 `debugMode` 设置为 `true`：

```javascript
debugMode: true  // 将此行改为 true
```

启用后会显示调试按钮：
- **测试功能**：显示当前游戏状态信息
- **清除缓存**：清除本地存储的数据

### 调试命令

在控制台中可以使用以下命令：

```javascript
// 查看当前游戏状态
console.log('当前数据:', getCurrentPages()[0].data);

// 查看数独板状态
console.log('游戏板:', getCurrentPages()[0].board);

// 手动触发新游戏
getCurrentPages()[0].startNewGame();
```

## 🐛 常见错误及解决方案

### 错误1：`setData` 错误
```
错误信息：setData 的数据格式不正确
```
**解决方案**：
- 确保传递给 `setData` 的数据是普通对象
- 检查对象深层嵌套是否过深
- 避免在 `setData` 中传递函数或未序列化的对象

### 错误2：事件绑定失败
```
错误信息：bindtap 事件未触发
```
**解决方案**：
- 检查方法名是否与 WXML 中的绑定一致
- 确认方法在 Page 对象中正确定义
- 检查事件参数传递是否正确

### 错误3：样式不生效
```
现象：WXSS 样式未应用
```
**解决方案**：
- 检查选择器优先级
- 确认使用了正确的 rpx 单位
- 在不同模拟器中测试

## 🛠️ 高级调试技巧

### 1. 使用断点调试
1. 在开发者工具中打开源码面板
2. 在 JS 文件中点击行号设置断点
3. 触发相关功能观察变量变化

### 2. 真机调试
1. 点击开发者工具的"真机调试"
2. 扫描二维码在手机上运行
3. 查看真机上的实际表现

### 3. 自定义调试信息
在关键位置添加调试日志：

```javascript
console.log('函数执行:', arguments);
console.log('数据更新:', newData);
```

### 4. 性能测试
```javascript
// 测试函数执行时间
const startTime = Date.now();
// 执行代码
const endTime = Date.now();
console.log('执行时间:', endTime - startTime, 'ms');
```

## 🚨 紧急处理

### 小程序崩溃
1. 检查控制台错误堆栈
2. 确认所有依赖文件都存在
3. 尝试清除缓存重新编译

### 数据异常
1. 使用调试按钮清除缓存
2. 检查本地存储的数据格式
3. 重置应用数据
