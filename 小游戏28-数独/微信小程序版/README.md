一个功能完整、界面紧凑的数独游戏微信小程序，专为移动设备优化，符合小程序使用习惯。

- 数独网格占据主要视觉空间

## 🚀 快速开始

### 环境要求
- 微信开发者工具 1.05.2109102 或以上版本
- Node.js 14.0.0 或以上版本

### 安装步骤

1. **下载项目**
   ```bash
   git clone <repository-url>
   cd sudoku-master-miniprogram
   ```

2. **打开微信开发者工具**
   - 导入项目，选择 `微信小程序版` 目录
   - 填入你的 AppID（可在微信公众平台申请）

3. **配置项目**
   - 在 `project.config.json` 中设置你的 AppID
   - 在 `app.json` 中可以自定义导航栏样式

4. **运行项目**
   - 点击"编译"或"预览"按钮
   - 在微信中扫码体验

## 🎮 游戏玩法

### 界面布局
```
┌─────────────────────────────────┐
│ [难度] [模式] [📊] [📝] [⚙️]     │  ← 顶部工具栏
├─────────────────────────────────┤
│ [时间] [提示] [错误]             │  ← 游戏状态栏
├─────────────────────────────────┤
│                                 │
│        数独游戏网格             │  ← 主要游戏区域
│                                 │
├─────────────────────────────────┤
│ [↶] [💡] [🎮] [✅] [🗑️]        │  ← 底部工具栏
└─────────────────────────────────┘
```

### 操作说明
- **顶部工具栏**: 快速切换难度和模式，查看统计，切换笔记模式，打开设置
- **游戏状态栏**: 显示时间、提示使用次数、错误次数
- **数独网格**: 点击单元格输入数字，游戏的主要交互区域
- **底部工具栏**: 核心游戏操作按钮

### 基本操作
- **点击单元格**: 选中要填写的格子
- **输入数字**: 直接在键盘输入1-9的数字
- **笔记模式**: 点击顶部📝按钮切换笔记模式

### 游戏模式
- **经典模式**: 传统数独规则，无时间限制
- **计时模式**: 比赛时间，挑战速度
- **禅境模式**: 完全自由，无约束游戏

### 工具使用
- **↶撤销**: 撤销上一步操作
- **💡提示**: 获取智能提示
- **🎮新游戏**: 开始新的一局游戏
- **✅验证**: 检查当前解是否正确
- **🗑️清除**: 清空选中的单元格

## 🔧 技术实现

### 核心算法
- **数独生成**: 使用回溯算法生成完整解
- **难度控制**: 通过移除数字数量控制难度
- **解唯一性**: 确保每个谜题有唯一解
- **验证逻辑**: 实时验证数独规则

### 数据存储
- **本地存储**: 使用 `wx.setStorageSync` 存储设置和统计
- **游戏状态**: 自动保存当前游戏进度
- **统计数据**: 记录游戏表现和历史

### UI组件
- **自定义组件**: 基于微信小程序原生组件
- **动画效果**: 使用CSS3和微信小程序动画API
- **响应式布局**: 适配不同屏幕尺寸

## 🎯 数独规则

数独是一个9x9的网格游戏，需要在每个单元格中填入1-9的数字，满足以下条件：

1. **行规则**: 每行必须包含1-9的所有数字，各不相同
2. **列规则**: 每列必须包含1-9的所有数字，各不相同
3. **宫规则**: 每个3x3的小宫格必须包含1-9的所有数字，各不相同
